# 🚗 ParkXcel – Vehicle Parking Application (Frontend)

Frontend for **ParkXcel**, a smart vehicle parking management application designed to provide an interactive and user-friendly interface for managing parking operations.

## 🌐 Live Application

🚀 https://parkxcel.netlify.app/

---

## 🛠️ Tech Stack

- Vue.js
- JavaScript
- HTML
- CSS
- Bootstrap

---

## ✨ Features

- User-friendly and responsive interface
- Role-based access interface
- Interactive parking management workflows
- Admin dashboard functionality
- Component-based frontend architecture using Vue.js
- Responsive design using Bootstrap

---

⚙️ Getting Started
1. Clone the repository
   git clone https://github.com/AnshiHub19/ParKXcel-vehicle_parking_app-FRONTEND.git
3. Navigate to the project directory
   cd ParKXcel-vehicle_parking_app-FRONTEND
5. Install dependencies
   npm install
7. Run the development server
   npm run serve

The application will start on a local development server.
